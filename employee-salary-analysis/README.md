
# Employee Salary Analysis

### Overview

Analyzed employee salary and workforce data to identify compensation trends and workforce insights.

## Purpose of the Project

The purpose of this project is to analyze employee salary and workforce data using SQL. The project explores employee demographics, compensation trends, departmental information, and workforce metrics to generate meaningful business insights.

In addition to data analysis, the project demonstrates advanced SQL concepts such as Common Table Expressions (CTEs), temporary tables, stored procedures, triggers, events, and window functions, providing hands-on experience with both analytical and database management techniques.
## Key Objectives
- Analyze employee salary distributions and workforce demographics.
- Compare salaries across different age groups, departments, and job roles.
- Identify trends and patterns in employee compensation.
- Practice advanced SQL techniques used in real-world business environments.
- Automate database tasks using procedures, triggers, and events.
- Develop analytical skills for HR and workforce-related reporting.
- Improve proficiency in SQL querying, data manipulation, and database management.
### Key Skills

* Joins
* Aggregate Functions
* Subqueries
* Window Functions
* CTEs
* Stored Procedures
* Triggers
* Events

### Business Problem Solved

Generated workforce and compensation insights that support HR reporting and salary analysis.
