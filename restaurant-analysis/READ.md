
## Restaurant Sales & Customer Behavior Analysis

### Overview
This project focuses on analyzing restaurant menu and order data using SQL to uncover customer ordering behavior, spending patterns, and menu performance.
## Purpose of the Project

The purpose of this project is to analyze restaurant sales and customer ordering behavior using SQL. By exploring menu items and order transactions, the project identifies customer preferences, spending habits, popular menu categories, and overall business performance.

This analysis helps uncover actionable insights that can support menu optimization, increase revenue opportunities, and improve customer satisfaction. The project also demonstrates how SQL can be used to transform raw transactional data into meaningful business intelligence.

## Key Objectives
- Analyze restaurant sales performance and customer purchasing trends.
- Identify the most and least popular menu items.
- Determine top-selling categories and revenue-generating products.
- Evaluate customer spending behavior and order patterns.
- Discover peak demand areas through order analysis.
- Generate business insights that can support menu and pricing decisions.
- Practice SQL querying, aggregation, joins, subqueries, and analytical techniques used in real-world data analysis.
## Questions Answered
1. How many menu items are available?
2. What are the least and most expensive menu items?
3. Which menu categories contain the most items?
4. Which menu items are ordered the most and least frequently?
5. What are the top 5 highest-spending orders?
6. How many items are included in the highest-spending orders?
7. Which menu categories generate the most customer demand?
8. What is the average spending per order?
9. Which menu items contribute the most to restaurant sales?
10. What customer ordering patterns can be identified from the data?
