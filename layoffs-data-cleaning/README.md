
## Layoffs Data Cleaning

### Overview

Cleaned and standardized a real-world layoffs dataset to improve data quality and prepare it for analysis.
## Purpose of the Project

The purpose of this project is to clean and prepare a real-world layoffs dataset for accurate analysis and reporting. Raw datasets often contain duplicate records, inconsistent formatting, missing values, and data quality issues that can lead to unreliable insights.

Through SQL data cleaning techniques, this project transforms the raw dataset into a structured and analysis-ready format by removing duplicates, standardizing values, handling nulls, correcting data types, and improving overall data quality. The cleaned dataset can then be used confidently for exploratory data analysis, reporting, and business intelligence projects.

## Key Objectives
- Improve data quality and consistency.
- Remove duplicate and inaccurate records.
- Handle missing and incomplete data.
- Standardize text, dates, and categorical values.
- Create a reliable dataset for future analysis and visualization.
- Demonstrate practical SQL data cleaning skills used by data analysts in real-world projects.

### Key Skills

* Data Cleaning
* ROW_NUMBER()
* CTEs
* UPDATE & DELETE
* NULL Handling
* String Functions
* Date Formatting

### Business Problem Solved

Prepared messy raw data by removing duplicates, handling missing values, standardizing records, and improving overall data quality.
